Federal Reserve Bank of Atlanta · Market Probability Tracker

Field Definitions

Column and field-value definitions for the MPT distribution dataset, as documented in the workbook's DICTIONARY sheet.

← Back to MPT Data Explorer

The Market Probability Tracker uses Chicago Mercantile Exchange (CME) 3-month SOFR options to estimate the probability distributions implied by their prices and specified reference window. The statistics below are generated from those distributions, organized by date and reference window.

Columns

date
Observation date.
reference_start
Start date of the 3-month window referenced by CME 3-month SOFR contracts.
target_range
FOMC federal funds rate target range on the indicated observation date.
field
Statistic generated from the distribution estimated by the Market Probability Tracker — see field values below.
value
The value of the indicated statistic.

Field values

Each observation date × reference window pair carries a full set of these fields, describing the estimated distribution of average SOFR over that reference window.

Rate statistics (basis points)

Rate: 25th percentile
The rate, in basis points, associated with the 25th percentile of the estimated distribution for a given reference window.
Rate: mean
The rate, in basis points, associated with the mean of the estimated distribution for a given reference window.
Rate: mode
The rate, in basis points, associated with the mode of the estimated distribution for a given reference window.
Rate: 75th percentile
The rate, in basis points, associated with the 75th percentile of the estimated distribution for a given reference window.

Probability statistics (percent)

Prob: cut
The probability, in percent, that average SOFR over the reference window will be below the FOMC's target range.
Prob: hike
The probability, in percent, that average SOFR over the reference window will be above the FOMC's target range.
Prob: various 25bps ranges
The probability, in percent, that average SOFR over the reference window will fall between a given 25bps range (e.g. Prob: 475bps - 500bps).
